  1. ヒットアンドブローの仕様                                                             

  基本ルール(数字版 / Bulls and Cows)                                                     
  - 出題者が決めた秘密の数字(通常4桁・重複なし)を推理して当てる
  - 推理ごとに「ヒット=数字も位置も一致した個数」「ブロー=数字は含まれるが位置違いの個数」
  が返る                                                                                  
  - 全桁ヒットで正解。4桁重複なしなら理論上最大7手で解ける                                
  - 根拠: https://en.wikipedia.org/wiki/Bulls_and_Cows

  アソビ大全51版「ヒット&ブロー」                                                       
  - 数字ではなく6色のピン(赤・青・黄・緑・白・ピンク)から4つの並びを当てるマスターマインド
  形式                                                                                    
  - 判定は赤ピン=ヒット、白ピン=ブロー(個数のみで位置は分からない)                        
  - 推理は合計8回まで。「同じ色あり/なし」のオプションあり        
  - 1〜2人用。2人(またはCPU戦)では同じ答えを交互に推理し、先に4ヒットを出した方が勝ち。相
  手の推理と判定結果も見えるのが駆け引き要素                                             
  - 根拠: https://www.nintendo.com/jp/switch/as7ta/games/                                 
  (公式・人数/ジャンル)、8回制限や交互進行は https://gamefaqs.gamespot.com/switch/286602-c
  lubhouse-games-51-worldwide-classics/faqs/78437/hit-and-blow
  等の複数攻略記事で一致(公式ページには回数の明記なし)                                    

  仕様上の注意点: 「同じ色あり」の場合、ブローは「色ごとに出現数の小さい方の合計 −
  ヒット数」で数えるのが標準(マスターマインド判定)。重複ありにするかどうかで判定ロジックの
  仕様が変わります。                                                                      

  2. make15 の技術(ワークスホルダー配下)

  Even G2向け2048系パズル「Make⑮」。TypeScript +
  Vite、フレームワークなし、@evenrealities/even_hub_sdk でグラスと通信する構成です。      

  - 構成: スマホ側WebView(設定・デバッグ)+
  グラス側描画をブリッジ経由で行う。画面は576×288px                                       
  - 描画: テキストコンテナ(Unicode文字で盤面描画)+ 1-bit
  PNG画像。実機のコンテナ上限はテキスト8+画像4(シミュレーターはバグで4)
  - 入力: タップ(クリック/ダブルクリック/前後スワイプ)+
  IMUによる首振りジェスチャ(キャリブレーション+ヒステリシス実装済み)                      
  - 開発フロー: npm run dev → QRでグラス接続、evenhub pack で .ehpk 化、GitHub
  Pagesへデプロイ、headlenss連携済み                                                      
  - handover.md に実機とシミュレーターの差異など重要な知見あり(2026-07-28更新)
